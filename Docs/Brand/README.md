# LibreReplace brand assets

The icon is intentionally simple at small macOS sizes: two rounded application tiles connected by one forward transition mark. It contains no text, currency symbol, recycle mark, or third-party logo.

- `LibreReplaceIcon.svg` — maintainable vector source
- `LibreReplaceIcon-1024.png` — 1024×1024 icon preview/source raster
- `LibreReplaceMark-1024.png` — transparent logo mark for non-app-icon use
- `favicon-64.png` / `favicon-32.png` — small web/document marks
- `github-social-preview-1280x640.png` — GitHub social preview with no fabricated UI

The Xcode AppIcon asset set is generated from the same 1024 px source under `App/LibreReplaceApp/Assets.xcassets/AppIcon.appiconset`.
