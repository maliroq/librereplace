# Code of Conduct

Be respectful, specific, and constructive. Critique code and claims, not people. Do not harass, threaten, discriminate against, dox, or intentionally expose another person's private information.

Maintainers may edit or remove abusive content and restrict participation when necessary to keep the project safe and useful. Good-faith disagreement about feature parity, licensing, privacy, or technical design is welcome when supported with evidence.
