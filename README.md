<h1 align="center">LibreReplace</h1>

<p align="center"><strong>Keep the workflow. Skip the subscription.</strong></p>

<p align="center">Meet the native Mac app that helps you replace expensive software with a smarter setup of free apps and built-in tools.</p>

<p align="center"><strong>Explore free options · Combine what works · Try before you switch</strong></p>

---

## One paid app. A whole new way to replace it.

Finding a free alternative is easy. Finding one that handles **everything you actually use** is the hard part.

LibreReplace turns that problem into a plan. Pick a paid Mac app, choose the features you care about, and explore free setups built around those requirements. Sometimes one app does the job. Sometimes the answer is **two great free tools working together**. LibreReplace helps you see the difference, try the pieces available on your Mac, and save the setup you want.

**It's not another list of alternatives. It's a way to build your next workflow.**

## The five parts of your next free setup

| | What you can do |
|---|---|
| **Discover** | Search 45 popular commercial Mac apps. Choose your essential features and compare free apps **or combinations** that cover them. |
| **My Setups** | Save the exact apps, tools and requirements you picked. Return whenever you're ready, adjust your plan, and keep track of tasks you've tested. |
| **Tools** | Extract text from screenshots and PDFs, combine PDFs, make searchable PDFs, work with supported PDF repairs, and convert images—all inside LibreReplace. |
| **Community** | Export and import reusable replacement recipes. Share a setup you've built and help other Mac users discover a better workflow. |
| **My Mac** | See your installed apps, spot matching alternatives and explore potential savings from subscriptions you choose to replace. |

## The clever part: build a free stack, not just a substitute

**What if no single free app does everything?** That's where LibreReplace gets interesting.

Imagine replacing a screenshot utility such as **CleanShot X**. You want quick screenshots *and* text extraction. LibreReplace can pair a free capture app with **LibreReplace Image OCR**—two tools presented as one coherent setup, organized around your must-haves.

Or start with **Adobe Acrobat Pro**, **Photoshop**, **Transmit** or **TextExpander**. Instead of browsing an endless list of app names, choose what matters and see how available alternatives line up against those tasks.

**45 paid-app targets. 70 free-alternative comparisons. 100 distinct catalog products.** One place to explore what fits.

## Your Mac already has part of the answer

LibreReplace includes a practical toolkit you can use without signing up for another service:

- **Extract text:** turn screenshots, images and supported PDFs into editable text with on-device processing.
- **Combine PDFs:** bring selected documents together in the order you want.
- **Make PDFs searchable:** add a searchable text layer to supported scanned documents.
- **PDF Rescue:** try built-in recovery operations for supported PDF problems.
- **Convert images:** change image formats from inside the app.

Better still, when a setup calls for one of these tools, LibreReplace can open the right tool and take you **back to the same setup** afterward.

## From “maybe” to a plan you can actually use

**Discover → Choose your must-haves → Explore a free setup → Try a task → Save your plan.**

You can do all of that before installing a replacement. LibreReplace shows what's already available on your Mac, makes optional installs easy to review, and keeps your original software in place while you decide.

For supported changes, Guided Switch provides previews, installation approvals, backups and recovery. Specific migration workflows include **Sublime Text → Zed** settings and **TextExpander → Espanso** snippets.

And when you find a combination worth keeping, **My Setups remembers the exact one you chose**, not a different recommendation generated later.

## Built for a better Mac experience

- **Native SwiftUI app.** Familiar macOS navigation, search, controls and dark-mode styling.
- **Private by design.** App detection and recommendations run locally; document tools work on files you choose. No account, ads or telemetry.
- **Your decisions stay yours.** Compare first, install only what you approve and test the tasks that matter to you.
- **Share the good discoveries.** Portable Community recipes let useful free setups grow beyond one person's Mac.
- **Open source.** Inspect the code, improve the catalog and help make the next great free setup easier to find.

## Get LibreReplace

**LibreReplace Studio — latest source experience**

The new Discover, My Setups, Tools, Community and My Mac workflow is available in the current source. To build it on your Mac:

```bash
git clone https://github.com/maliroq/librereplace.git
cd librereplace
brew install xcodegen
./Scripts/install_local.sh
```

You'll need macOS 14+, Xcode, Python 3 and XcodeGen. See [building from source](Docs/BUILDING.md) for the full setup.

**Want the existing downloadable preview?** The [v0.2.0-preview.1 release](https://github.com/maliroq/librereplace/releases/tag/v0.2.0-preview.1) and `brew install --cask maliroq/tap/librereplace` remain available. That download is the earlier comparison-focused edition; the new Studio experience is currently available from source while its next downloadable build is prepared.
